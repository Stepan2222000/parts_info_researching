1. Используй только сохраненные Exa JSON. В интернет, fetch, web search, MCP, браузер и другие файлы не ходи.
2. Итоговый JSON должен быть валидным, на русском и строго по схеме. Лишние поля не добавляй.
3. Не придумывай данные. Если Exa не подтверждает поле, ставь null, пустую строку, пустой массив или пустой объект по схеме.
4. Используй только источники, где явно есть входной артикул или его нормализованный OEM-вариант. Похожие номера без точного совпадения игнорируй.
5. Номерные поля только для OEM. Aftermarket-бренды и SKU продавцов не пиши в article, article_low_confidence или irrelevant. Из таких источников можно взять только явно указанный OEM-номер.
6. Mercury, MerCruiser, Quicksilver и Mariner считай OEM-брендом Mercury Marine.
7. Нормализуй дубли одного OEM-номера: для Mercury/Quicksilver убирай групповой префикс до дефиса, если справа полный номер, например 87-892150Q02 -> 892150Q02. Суффиксы продавца/бренда тоже убирай, например 24677251-VP -> 24677251.
8. numbers.article содержит только подтвержденные OEM-кроссы. Сначала новые/актуальные номера, потом старые. Поля type и confidence не добавляй.
9. numbers.article_low_confidence содержит только возможные OEM-кроссы, которым не хватает доказательств. Не клади туда aftermarket, SKU продавцов и дубли после нормализации.
10. numbers.irrelevant содержит только явно отброшенные OEM-похожие номера другой OEM-детали. Aftermarket и SKU продавцов туда не переноси.
11. В каждом article, article_low_confidence и irrelevant нужны source_url и evidence на русском. Для low_confidence нужен why_low_confidence. Для irrelevant нужен why_irrelevant.
12. kit_contents заполняй только если входной артикул сам явно назван kit, set, комплект, набор, repair kit, tune-up kit, anode kit или похожим полным набором.
13. Никогда не добавляй входной артикул как компонент самого себя в kit_contents. Если входной артикул одиночная деталь, а рядом продается другая деталь, kit_contents оставь пустым.
14. part_of_kits используй, когда входной артикул входит в другой набор или связку. Если номера набора нет, ставь kit_article: null и объясняй это в evidence.
15. Запись вида "деталь A + деталь B" не делает входной артикул набором. Это part_of_kits, если только источник прямо не говорит, что входной артикул сам является номером набора.
16. Вес всегда указывай в килограммах. Фунты, унции и граммы переводи в кг. Если веса нет, weight = null.
17. models должен быть null или объектом с text, source_urls и evidence на русском. Каждую подтвержденную применяемость пиши с новой строки.
